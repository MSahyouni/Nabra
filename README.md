# نَبْرَة

تطبيق مكتبي عربي لتسجيل الاجتماعات وتفريغها وتلخيصها محليًا.

نَبْرَة مبني على:

- Tauri + Rust للتطبيق المكتبي والتسجيل المحلي.
- Next.js + React للواجهة.
- منطق نَبْرَة المحلي: Rust audio pipeline، Whisper، SQLite،
  ومحرك التلخيص داخل Tauri.

## الهوية البصرية

يعتمد التطبيق على الهوية البصرية السورية كما وردت في Syrian Zone:

- Forest: `#428177`, `#054239`, `#002623`
- Golden Wheat: `#edebe0`, `#b9a779`, `#988561`
- Deep Umber: `#6b1f2a`, `#4a151e`, `#260f14`
- Charcoal: `#ffffff`, `#3d3a3b`, `#161616`

التفاصيل موثقة في:

`docs/nabra-syrian-visual-identity.md`

## نطاق النسخة الحالية

مفعّل الآن:

- التسجيل والتفريغ المحلي.
- Whisper داخل Rust.
- التلخيص وNLP.
- قاعدة بيانات محلية للاجتماعات والنصوص والملخصات.

غير مفعّل الآن حسب قرار المشروع:

- auth
- billing
- TTS
- أي اعتماد على Python أو FastAPI sidecar
- محركات تفريغ إضافية خارج Whisper

## تشغيل الواجهة

```bash
cd frontend
pnpm install
pnpm tauri:dev
```

## ملاحظة معمارية

لا يوجد خادم Python في النسخة الجديدة. أي ميزة تُنقل من `meet-asr` يجب أن
تُعاد كتابتها أو دمجها فوق منطق Rust/Tauri الحالي.
