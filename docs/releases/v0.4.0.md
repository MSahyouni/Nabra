# نبرة 0.4.0

الإصدار الأول من نبرة بهويته السورية الجديدة، وهو مساعد اجتماعات عربي يعمل محلياً ويركّز على الخصوصية.

## أبرز التغييرات

- تعريب كامل مع دعم اتجاه RTL وخط قمرة العربي.
- تطبيق الهوية البصرية السورية وأيقونة النسر السوري الذهبي.
- تحسين التلخيص المحلي عبر Ollama ومعالجة النصوص الطويلة دون بتر صامت.
- إصلاح حالات فشل تنزيل نماذج الذكاء الاصطناعي ونسب التقدم غير الصالحة.
- تصدير الملخص والتفريغ إلى Microsoft Word عبر Word COM Engine.
- اعتماد CUDA 12.1 افتراضياً لبناء Whisper و`llama-helper`.
- مثبّت MBA عربي بواجهة تثبيت وإزالة تثبيت موحّدة.
- فحص Windows x64 وOffice وVC++ وWebView2 وCUDA قبل التثبيت.
- تضمين VC++ وWebView2 داخل المثبّت، وتنزيل CUDA 12.1 من NVIDIA عند الحاجة.
- منع التثبيت افتراضياً ما لم يمنح خادم مشرفي النظام تصريحاً صالحاً.

## المتطلبات

- Windows 10 أو Windows 11 بنواة 64-bit.
- بطاقة NVIDIA وتعريف متوافق مع CUDA 12.1.
- Microsoft Word Desktop للاستفادة من تصدير Word.
- اتصال بالإنترنت عند الحاجة إلى تنزيل CUDA أو نماذج الذكاء الاصطناعي.

## تنبيه قبل النشر العام

هذه الحزمة معدّة كمسودة إصدار حتى يُضبط رابط خادم التصاريح الحقيقي وتُوقّع الملفات التنفيذية بشهادة توقيع كود موثوقة. الوضع الحالي مغلق افتراضياً ولن يسمح بتثبيت تفاعلي عبر عنوان الخادم الوهمي.
